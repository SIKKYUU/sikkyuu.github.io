# Academic Homepage for GitHub Pages

This folder contains a static academic homepage that can be published with GitHub Pages.

## Edit

- Replace `Your Name`, profile links, email, university, advisor, and research text in `index.html`.
- Replace publication titles, authors, venues, and links.
- Edit colors and spacing in `styles.css`.

## Publish With GitHub Pages

1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Upload the contents of this `site/` folder to the repository root.
3. In the repository settings, open Pages and deploy from the `main` branch.
4. Your site will appear at `https://<your-github-username>.github.io`.

For a project page instead, upload this folder to any repository and enable GitHub Pages for that repository.
